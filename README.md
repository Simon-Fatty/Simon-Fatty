# Simon Fatty

Jag studerar till **Moln- och virtualiseringsspecialist** på Campus Mölndal och söker en **LIA-plats** inom drift, infrastruktur eller moln. Här finns projekt från utbildningen: miljöer jag byggt, felsökt och dokumenterat, från Active Directory och Windows Server till Azure och AWS.

## Projekt

Azure- och AWS-kurserna ligger på mitt skolkonto [02simfat](https://github.com/02simfat), där jag fortsätter arbeta under kurserna. Övriga projekt ligger här.

| Projekt | Vad det visar |
| --- | --- |
| [azure-MOV25](https://github.com/02simfat/azure-MOV25) | Azure-kursen vecka för vecka, betyget VG. Examinationen är en hyresgästportal med VM Scale Set, lastbalanserare, Blob Storage, hanterad identitet och Power Automate, byggd från en ARM-template och skript. |
| [active-directory-powershell](https://github.com/Simon-Fatty/active-directory-powershell) | AD-design enligt AGDLP, Group Policy, Folder Redirection och ABE, byte av domänkontrollant, 17 egna PowerShell-skript och ett verktyg för tillfällig lokal admin |
| [hyperv-disaster-recovery](https://github.com/Simon-Fatty/hyperv-disaster-recovery) | En Disaster Recovery Plan som testades på riktigt: alla VM:ar raderades och återställdes, både på samma värd och på en annan dator |
| [AWS-MOV25](https://github.com/02simfat/AWS-MOV25) | AWS-kursen, pågår: EC2, IAM med least privilege och miljöer som byggs och rivs med skript |
| [onprem-infrastructure-projects](https://github.com/Simon-Fatty/onprem-infrastructure-projects) | Windows Server-miljöer med DFS, RDS, VPN, SCCM och Exchange, den största för 150 användare |
| [m365-power-platform](https://github.com/Simon-Fatty/m365-power-platform) | Supportsystem i Teams, SharePoint, Power Apps och Power Automate, Dataverse och Intune |

## Hur jag arbetar

Jag dokumenterar det jag bygger: hur det är uppbyggt, hur jag testade det och vad som gick fel. I grupparbeten står det vad som var gemensamt, och rättelser som gjorts i efterhand är märkta. När jag felsöker testar jag en sak i taget och skriver ner lösningen, så att den finns kvar nästa gång.
